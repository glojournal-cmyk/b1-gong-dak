Source: user-uploaded Grok workspace ZIP. This project copy is detached from the user's live Grok sandbox and from their child's Study App. Do not replace live deployments before full QA.

## Confirmed from source code

- The working **push-to-talk** UI records microphone input using `getUserMedia` and the Web Audio API, then prepares a 16 kHz WAV payload (`src/lib/mic.ts`).
- Speech is recognised through **xAI speech-to-text API** (`POST https://api.x.ai/v1/stt`, model `grok-voice-transcribe-2.0`).
- Tutor replies are generated by **xAI chat completions API** (`grok-4.20-0309-non-reasoning`); app sends recent message context (up to 16 turns) and scene prompt.
- Spoken tutor replies are rendered by **xAI text-to-speech API** (`POST https://api.x.ai/v1/tts`, voice `ara`).
- Scores also call the chat-completions API; a transcript alone cannot reliably assess listening or pronunciation.
- Thus a cloned deployment needs a provisioned xAI API key and may incur usage charges. **The original Grok sandbox's cost-bearing arrangement is not proved by this ZIP**; do not assume the sandbox link grants free API use after export.
- We found code paths expecting `XAI_API_KEY`, but this ZIP alone does not establish that a key is available for redeployment. No secrets are copied to GitHub by these changes.

## No-billing safety in this prototype

- All original xAI requests now require explicit `B1_ALLOW_BILLED_XAI=true` **as well as** `XAI_API_KEY`. By default, speech and generated responses will say unavailable, rather than silently billing. This switch is intentionally NOT enabled for the user, who refused paid API.
- The new learning curriculum data, progress stage selection, and topic forms do not need a paid API.
- A replacement **free** natural conversation engine must be established and QA'd (e.g. a compatible locally hosted language model). No such drop-in Android/server voice solution is confirmed.

## Official content corrections

- Trinity GESE Grade 5: prepared topic (five discussion points) + two of six examiner-selected conversation areas, around 10 minutes in total.
- Trinity recommends **not using family** as the candidate prepared topic. Family remains a beginner training theme but is marked as unsuitable for the actual prepared Topic Form.
- Original `scoreTalk` heuristically inferred "pass" from word count, reasons and questions. This has been changed to *non-official practice feedback* and cannot be sold as a pass predictor.
- In this branch, there is a five-stage scaffold/selector, topic-form content, six official conversation areas and coaching rules. It **does not yet include** automatic mastery-driven promotion, a complete authentic 10-minute mock, or a functioning free voice backend.
