# Acceptance before voice features
1. Install APK on Galaxy S21 and S22 Ultra; record CPU variant, RAM, Android OS, LiteRT-LM initialization latency and errors.
2. Import Qwen3-0.6B .litertlm model from Downloads; verify no model download hidden in app and airplane mode still works.
3. Send 5+ independent, natural follow-up turns. No fixed canned reply for unexpected text.
4. Confirm statements in personal-facts editor only. Confirm age unknown remains unknown until supplied.
5. Confirm no network permission, no tracking keys, no cloud calls.
6. Suspend/resume, force stop, re-open. History remains local; reinitialize engine safely.
7. Failure means *not yet usable*, not an automatic success.
8. Only after all tests pass consider offline text-to-speech and Android speech recognition (device support contingent).
